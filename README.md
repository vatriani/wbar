# wbar
a simple and very basic statusbar for wayland with a slightly hyprland integration by fetching the stylecolors.

uses:
- wayland-client
- cairo
- pango
- pangocairo

## make
<code>make</code>

## install
<code>make install</code>

## run
<code>wbar</code>

## integrate into hyprland
edit ~/.config/hypr/hyprland.conf with your favorite editor
- adding under keybindings <code></code>
